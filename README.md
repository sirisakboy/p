# ระบบบริการประชาชนส่วนกลาง (Police Portal)

## คำอธิบายโครงการ

นี่คือเว็บไซต์สาธารณะของ **สำนักงานตำรวจแห่งชาติ** ที่ให้บริการออนไลน์ต่าง ๆ แก่ประชาชน 24 ชั่วโมง ผ่านเทคโนโลยีเว็บสมัยใหม่ ใช้ **Tailwind CSS** ผ่าน CDN ทำให้ไม่ต้องทำการ build CSS ใด ๆ เพิ่มเติม

- หน้าแรก: แสดงข้อมูลและปุ่มเริ่มต้นใช้บริการ
- บริการสำคัญ: 
  - ตรวจสอบสถานะคดีออนไลน์
  - ตรวจสอบค่าสมัครคันไฟแดง
  - แจ้งเตือนภัยไซเบอร์
- รองรับการเข้าถึงจากอุปกรณ์มือถือและเดสก์ท็อป

## ขั้นตอนการตั้งค่า (สำหรับผู้พัฒนา)

1. **Clone Repository**
   ```bash
   git clone <repo‑url>
   cd <repo‑directory>
   ```
2. **ตรวจสอบไฟล์โครงสร้าง**
   - `src/index.html` – ไฟล์ HTML หลัก (คัดลอกมาจาก `info.md` ของโครงการ)
   - `README.md` – คู่มือนี้
   - `.gitlab-ci.yml` – คอนฟิก CI/CD สำหรับ GitLab Pages
   - `.gitignore` – ไฟล์ที่ต้องละเว้นจาก Git
3. **ทดลองรันบนเครื่อง**
   เปิดไฟล์ `src/index.html` ในเบราว์เซอร์ ดูว่า UI แสดงผลตามที่คาดไว้
4. **Deploy ไปยัง GitLab Pages**
   - เปิดใช้งาน **GitLab Pages** ใน Settings → Pages ของโปรเจกต์
   - ตรวจสอบว่าไฟล์ `.gitlab-ci.yml` อยู่ในรากของรีโพซิทอรี
   - Commit และ push การเปลี่ยนแปลงของคุณ Git จะทำการรัน pipeline โดยอัตโนมัติและเผยแพร่เว็บไซต์ที่ `https://<username>.gitlab.io/<project‑name>/`
5. **อัปเดตเนื้อหา**
   แก้ไข `src/index.html` หรือเพิ่มไฟล์อื่น ๆ แล้ว commit/push อีกครั้ง เว็บไซต์จะอัปเดตโดยอัตโนมัติ

## การทำงานร่วมกับ GitLab CI/CD

ไฟล์ `.gitlab-ci.yml` ในโครงการนี้ตั้งค่าอย่างง่ายเพื่อ deploy เว็บแบบ static:
- ใช้ Docker image `alpine:latest`
- คัดลอกไฟล์จาก `src/` ไปยังโฟลเดอร์ `public/`
- เก็บผลลัพธ์เป็น artifacts ให้ GitLab Pages ใช้

## ข้อควรระวัง

- อย่าลืมอัปเดต URL ของ **Tailwind CDN** หากมีการเปลี่ยนเวอร์ชัน
- ตรวจสอบว่าตำแหน่งไฟล์ `src/` ถูกต้องและไม่ถูกละเว้นใน `.gitignore`
